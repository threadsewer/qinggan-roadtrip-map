# 青甘环线 · 方案 A

2026 年 8 月 20–26 日青甘环线方案 A 的轻量出行页，包含全程总地图、全程海拔剖面、D1–D7 每日地图、天气趋势与执行说明，并针对深蓝 G318 四驱旷野版补充逐日油电策略。总图和每日地图均可缩放；每日地图可切换灰度路网、等高地形与柔化卫星三种离线背景。

网页通过 GitHub Pages 发布。路线采样位于 `plan-a-routes.js`，道路背景来自项目内的 OpenStreetMap 离线快照，高程与卫星背景分别位于 `plan-a-basemaps.js` 和 `qinggan-satellite.jpg`。天气为页面注明日期的趋势快照；路线、开放政策、宠物政策与路况均可能变化，出发前仍需核验最新预报、高德实时导航和官方公告。
